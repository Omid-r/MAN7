# MAN7 | پلتفرم جامع مهاجرت، ایمن‌سازی و ارتقاء آفلاین Splunk و RHEL

سامانه مهندسی **MAN7** یک پلتفرم ۱۰۰٪ آفلاین (Air-Gapped) برای مهندسان امنیت اطلاعات، زیرساخت شبکه و ادمین‌های Splunk Enterprise است که فرآیند ارتقاء نسخه به نسخه اسپلانک، مهاجرت امن کانفیگ‌ها و ایمن‌سازی لینوکس Red Hat Enterprise Linux (RHEL 7/8/9) را به صورت استاندارد خودکارسازی می‌کند.

---

## اجرای فوری روی ویندوز بدون نیاز به نصب هیچ برنامه‌ای (بدون Admin، بدون npm، بدون Node و بدون Java)

این پروژه از قبل بیلد (Pre-Built) شده و داخل پوشه **`windows-portable/`** در مخزن گیت قرار دارد تا روی سیستم‌های سازمانی محدود (بدون دسترسی Administrator و بدون نیاز به `npm` یا `Java`) بلافاصله اجرا شود:

### روش اول (پیشنهادی - با سرور داخلی Built-in ویندوز و اتصال زنده به پورت Root سرور لینوکس):
1. پروژه را از گیت دانلود (Clone یا Download ZIP) کنید.
2. بدون نیاز به دسترسی Admin و بدون نیاز به نصب هیچ برنامه‌ای، فقط روی فایل **`start-windows.bat`** دابل‌کلیک کنید.
3. این فایل با استفاده از ابزارهای **۱۰۰٪ پیش‌فرض خود ویندوز (`powershell.exe` و `.NET TcpListener` روی پورت کاربری `127.0.0.1:3000`)** سرور داخلی را بالا آورده و رابط کاربری را در مرورگر شما باز می‌کند.

### روش دوم (تک‌فایل مستقل `MAN7-Standalone.html` در ریشه پروژه - حتی بدون اجرای اسکریپت):
- در صفحه اول مخزن گیت، فایل بیلدشده و یکپارچه‌ی **`MAN7-Standalone.html`** قرار داده شده است (که تمام کدهای گرافیکی، استایل‌ها و اسکریپت‌ها در داخل همان یک فایل مجتمع شده‌اند).
- کافی است روی **`MAN7-Standalone.html`** (یا `windows-portable\ui\index.html`) دابل‌کلیک کنید تا برنامه مستقیماً در مرورگر (Edge / Chrome / Firefox) بدون نیاز به هیچ وب‌سرور یا نصبی باز شود.

## قابلیت‌های کلیدی نسخه MAN7

1. **اجرای ۱۰۰٪ Built-in روی ویندوز و لینوکس (Zero-Install & Non-Admin):**
   - سرور داخلی ویندوز (`windows-portable/man7-windows-builtin.ps1`) مبتنی بر کلاس‌های استاندارد `.NET Framework` (`TcpListener` و `TcpClient`) که روی تمام نسخه‌های ویندوز ۱۰ و ۱۱ به صورت پیش‌فرض وجود دارد و هیچ نیازی به دسترسی Administrator، Node.js، npm یا Java ندارد.
2. **اتصال مستقیم به پورت Root سرور لینوکس و ترمینال زنده داخل UI:**
   - باز کردن یک پورت دلخواه (مثلاً `9099`) روی سرور لینوکس مقصد با یک تک‌دستور (مبتنی بر `/usr/libexec/platform-python` که به صورت پیش‌فرض روی تمام سرورهای RHEL 8/9 نصب است) و اجرای مستقیم دستورات و آپلود فایل‌ها با دسترسی `root`.
3. **آپلود مستقیم فایل‌های آفلاین به مسیر نصب سرور (`/var/tmp` و `/opt/splunk-airgap`):**
   - ارسال مستقیم باینری‌های اسپلانک (`.tgz` / `.rpm`)، پکیج‌های پیش‌نیاز RHEL و فایل‌های کانفیگ از داخل مرورگر به پوشه دقیق نصب در سرور مقصد همراه با محاسبه چک‌سام **SHA-256**.
4. **محاسبه‌گر هوشمند مسیر ارتقاء چندمرحله‌ای (Multi-Hop Upgrade Matrix):**
   - محاسبه خودکار ایستگاه‌های میانی اجباری از نسخه `7.2.10` تا `9.4.0` (شامل ایستگاه‌های حیاتی `8.2.12` برای تبدیل موتور KV Store به `WiredTiger` و `9.0.9` برای حذف Python 2).
5. **اسکریپت گام A ویژه ویندوز Built-in (`step_a_windows_builtin.ps1`) و لینوکس (`step_a_online_collector.sh`):**
   - امکان دانلود فایل‌های آفلاین و ساخت باندل `.tar.gz` هم روی ویندوز (با ابزارهای پیش‌فرض ویندوز `curl.exe` و `tar.exe` بدون نیاز به Admin) و هم روی لینوکس.
